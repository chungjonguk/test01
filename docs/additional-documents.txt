               Bootstrap 5, OAuth2, KG Inicis PG, Git, Maven

    Falcon UI 템플릿 기반 관리자·이커머스 통합 웹 애플리케이션.
    240개 이상 화면, MySQL 30+ 테이블, 기동 시 DDL/시드 자동화.

  ■ 담당 업무 및 성과

    2) 인증: 카카오·네이버 OAuth, 세션 타임아웃, 접속 로그(user_access_log)

    4) 이커merce: 상품·이미지 관리, 체크아웃, 이니시스 표준결제·ecm_payment
    5) 기타: 캘린더 DB 연동, 카카오 주소/지도, 원화 표시·한글 폰트, Eclipse 연동
    6) 배포/운영: run-server.bat, MySQL 기동 검증, UTF-8 전역 설정
