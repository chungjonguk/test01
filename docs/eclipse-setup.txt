0. 워크스페이스 연동 (D:\sts-workspace ↔ spring-boot-app-fixed)
================================================================================

  폴더 구조:
    D:\sts-workspace\           ← STS 워크스페이스 (-data)
    ...\new-workspace\spring-boot-app-fixed\  ← 소스 (외부 경로 Import/등록)

  STS: C:\Users\chung\.local\dev\sts-5.1.1\sts-5.1.1.RELEASE\SpringToolsForEclipse.exe
  설정 파일: scripts/eclipse/sts-path.local.txt, sts-workspace.local.txt

  한 번에 연동 (권장):
    프로젝트 루트에서  sync-eclipse-workspace.bat  실행
    → JDK 17, Maven compile, .metadata 생성, spring-boot-app 등록,
      UTF-8·자동 빌드·새로고침 prefs

  ※ org.eclipse.m2e.core.maven2ProjectJob 은 STS에 없음.
    sync 스크립트는 mvn compile 로 대체하며, STS에서는 Alt+F5(Update Project)만 1회 확인.

  STS 설치 경로가 다른 PC 경로면:
    scripts/eclipse/sts-path.local.txt  — SpringToolsForEclipse.exe 경로
    scripts/eclipse/sts-workspace.local.txt  — D:\sts-workspace

  STS 열기 후 Package Explorer에 spring-boot-app 이 보이면 Import 생략.
  보이지 않으면 File → Import → Maven → Existing Maven Projects.

  Cursor 와 동일 소스: 두 IDE 모두 spring-boot-app-fixed 폴더만 엽니다.

================================================================================
1. 프로젝트 가져오기
================================================================================

■ 방법 A — Maven 프로젝트 Import (권장)

  1) File → Import → Maven → Existing Maven Projects
  2) Root Directory: pom.xml 이 있는 프로젝트 루트 폴더 선택
     (예: spring-boot-app-fixed)
  3) Projects 목록에서 spring-boot-app 체크 → Finish
  4) 프로젝트 우클릭 → Maven → Update Project (단축키 Alt+F5)
     - Force Update of Snapshots/Releases 체크 → OK

■ 방법 B — Eclipse 메타데이터 + STS 워크스페이스

  저장소에 .project, .classpath, .settings, .launch 가 있을 때:

  1) open-sts-workspace.bat 실행
     - STS 워크스페이스: D:\sts-workspace
  2) 최초 1회: scripts\eclipse\import-maven-project.bat 안내 참고
  3) File → Open Projects from File System 또는 Maven Import
  4) Maven → Update Project 실행
  5) JDK 경로: powershell -File scripts\eclipse\apply-jdk17.ps1

  점검: backup-and-eclipse.bat 또는 scripts\eclipse\verify-eclipse-setup.ps1

================================================================================
2. JDK 17 설정
================================================================================

  1) Window → Preferences → Java → Installed JREs
     - JDK 17 추가 후 default(기본) 로 지정

  2) Window → Preferences → Java → Compiler
     - Compiler compliance level: 17

  3) 프로젝트 우클릭 → Properties → Java Build Path → Libraries
     - JRE System Library 가 JavaSE-17 인지 확인

================================================================================
3. UTF-8 설정 (한글 깨짐 방지)
================================================================================

  자동 (권장):
    fix-eclipse-utf8.bat  — STS ini + D:\sts-workspace + 프로젝트 .settings
    적용 후 STS 완전 종료 → 다시 실행

  에디터에서만 깨질 때 (.properties 등):
    · 원인: Java Properties 기본 인코딩이 ISO-8859-1 (Eclipse 잠금)
    · fix-eclipse-utf8.bat 가 content-type UTF-8 오버라이드 적용
    · 파일 우클릭 → Open With → Generic Text Editor (또는 Text Editor)
    · Window → Preferences → General → Editors → File Associations
      *.properties → Generic Text Editor 를 Default 로 지정
    · 파일 우클릭 → Properties → Resource → Text file encoding → UTF-8

  수동 확인:
  1) Window → Preferences → General → Workspace
     - Text file encoding: UTF-8

  2) Window → Preferences → Run/Debug → Console
     - Default console encoding: UTF-8

  3) Java → Installed JREs → JDK 17 → Default VM arguments:
     -Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8

================================================================================
4. 애플리케이션 실행
================================================================================

■ Run Configuration (프로젝트에 포함된 설정)

  Run → Run Configurations 또는 Debug Configurations:

  [ spring-boot-app-java ]
    - SpringBootAppApplication Java Application 실행
    - 메인 클래스: com.example.springbootapp.SpringBootAppApplication

  [ spring-boot-app-maven ]
    - mvn clean spring-boot:run -DskipTests
    - MySQL 이 먼저 기동되어 있어야 함

  .launch 폴더에서 가져오기:
    Run Configurations → 해당 유형 → Import launch configurations
    → .launch 폴더 선택

■ STS Spring Boot Dashboard (STS 설치 시)

  1) Window → Show View → Other → Spring → Boot Dashboard
  2) spring-boot-app 프로젝트 → (Re)start

■ Eclipse 밖에서 실행 (Windows)

  프로젝트 루트에서 run-server.bat 실행
  - MySQL 확인/기동
  - 8081 포트 정리
  - mvn clean spring-boot:run

6. 자주 나는 문제
================================================================================

  [ Maven 의존성 오류 / 빨간 느낌표 ]
    → 프로젝트 우클릭 → Maven → Update Project

  [ target 없음, 클래스를 찾을 수 없음 ]
    → Run As → Maven build… → Goals: compile
    → 또는 터미널: mvn compile

  [ Spring Boot nature / springbootbuilder 오류 ]
    → Spring Tools 4(STS) 플러그인 설치
    → 또는 Java Application 실행만 사용 (spring-boot-app-java)

  [ DB 연결 실패 ]
    → MySQL 서비스 기동
    → DB spring_boot_app 존재 여부 확인
    → application.properties 의 datasource 설정 확인
    → application-local.properties.example 참고 (로컬 비밀번호)

  [ 포트 8081 이미 사용 중 ]
    → run-server.bat (8081 프로세스 종료 포함)
    → 또는 netstat / taskkill 로 해당 PID 종료
