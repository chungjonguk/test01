3. 데이터베이스 (PostgreSQL 16)
--------------------------------------------------------------------------------

  [호스트 설치 — 현재 PC 기본]

  Host                : localhost  (또는 127.0.0.1)
  Port                : 5432
  Database            : spring_boot_app
  User                : postgres
  Password            : postgres

  JDBC URL            : jdbc:postgresql://localhost:5432/spring_boot_app

  application.properties:
    spring.datasource.url=jdbc:postgresql://localhost:5432/spring_boot_app
    spring.datasource.username=postgres
    spring.datasource.password=postgres

  상태 확인:
    pg_isready -h localhost -p 5432

  DB 생성 (최초 1회):
    CREATE DATABASE spring_boot_app;


  [Docker 사용 시 — docker-compose.yml]

  Host Port           : 5433  →  컨테이너 5432
  User                : appuser
  Password            : apppass
  JDBC URL            : jdbc:postgresql://localhost:5433/spring_boot_app
  앱 프로파일         : SPRING_PROFILES_ACTIVE=docker

  ※ 호스트 PG(5432)와 Docker PG(5433) 동시 기동 가능하나, 앱 접속 URL을 맞출 것


  [DBeaver 연결]

  가이드              : scripts\dbeaver-postgresql-connection.txt
  JSON 예시           : scripts\dbeaver-setup\data-sources.example.json

  연결 절차 요약:
    1) 새 연결 → PostgreSQL
    2) Host localhost, Port 5432, DB spring_boot_app
    3) User postgres / Password postgres
    4) Test Connection → 드라이버 Download → Finish


  [스키마·DDL]

  자동 적용 SQL       : src\main\resources\schema\*.sql
  적용 순서 정의      : src\main\java\...\config\SchemaScriptCatalog.java
  수동 일괄 실행      : schema\00_create_all_tables.sql
                        schema\01_seed_all.sql
  자동 적용 설정      : app.schema.auto-apply=true
  기동 시 DB 확인     : app.datasource.startup-check=true
  정상 테이블 수      : public 스키마 약 42개

7. 환경변수
--------------------------------------------------------------------------------
