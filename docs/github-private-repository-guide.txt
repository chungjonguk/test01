================================================================================
  GitHub 저장소 비공개(Private) 설정 — 다른 사람 clone/pull 차단
================================================================================

※ 로컬 Git 설정만으로는 불가능합니다. GitHub 웹 또는 gh CLI로
  저장소 visibility 를 Private 으로 바꿔야 합니다.

저장소: https://github.com/chungjonguk/test01


--------------------------------------------------------------------------------
방법 A — GitHub 웹 (권장, 로그인만 있으면 됨)
--------------------------------------------------------------------------------

1. 브라우저에서 로그인 (계정: chungjonguk 소유자)
   https://github.com/login

2. 저장소 설정 페이지 열기
   https://github.com/chungjonguk/test01/settings

3. 맨 아래 "Danger Zone" 섹션

4. "Change repository visibility" → "Change visibility" 클릭

5. "Make private" 선택
   - 설명 확인 후 저장소 이름(test01) 입력

6. 확인 후 완료

[추가 권장]
- Settings → Collaborators: 불필요한 협업자 제거
- Settings → Actions / Pages: 사용 안 하면 비활성 검토
- 이미 공개였던 기간에 clone 한 복사본은 GitHub 밖에 남을 수 있음
- project-accounts.txt 등에 비밀번호가 있었다면 비밀번호·PAT 변경 권장


--------------------------------------------------------------------------------
방법 B — GitHub CLI (scripts/github-make-private.bat)
--------------------------------------------------------------------------------

1. 터미널에서 프로젝트 scripts 폴더의 배치 실행
   github-make-private.bat

2. gh auth login 안내에 따라 GitHub 로그인 (브라우저)

3. 스크립트가 자동으로 private 전환 시도


--------------------------------------------------------------------------------
비공개 전환 후 동작
--------------------------------------------------------------------------------

  - 로그인·권한 없는 사용자: clone, pull, zip 다운로드 불가
  - 소유자·초대된 Collaborator 만 접근 가능
  - 본인 PC: 기존 remote 그대로 push/pull 가능 (인증 필요)


--------------------------------------------------------------------------------
완전히 원격 사용 안 함 (로컬만 보관)
--------------------------------------------------------------------------------

  git remote remove origin
  → GitHub 와 연결 끊김 (로컬 히스토리는 유지)
