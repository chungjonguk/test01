2. 웹 애플리케이션 로그인 (user 테이블)
--------------------------------------------------------------------------------

  서버 포트    : 8081
  브랜드명     : PrintMall (app.brand-name)

  로그인 화면  : http://localhost:8081/pages/authentication/simple/login
  로그인 처리  : POST /auth/login  (파라미터: id, pw)
  로그아웃     : GET 또는 POST /auth/logout
  회원가입     : http://localhost:8081/pages/authentication/simple/register

  인증 방식    : user 테이블 id/pw — 평문 비교 (BCrypt 미사용)
  기본 계정    : 시드 SQL 없음 — 회원가입으로 user 테이블에 직접 등록 필요

  비밀번호 정책 (회원가입 시):
    - 영문자, 숫자, 특수문자 각 1자 이상 포함

  세션         : 비활성 10분 후 만료
    - server.servlet.session.timeout=10m
    - app.auth.session-timeout-minutes=10

  등록된 계정 확인 (MySQL):
    USE spring_boot_app;
    SELECT id, name, email FROM user;

3. 소셜 로그인 (OAuth)
--------------------------------------------------------------------------------

  [카카오]
  설정 키           : kakao.client-id, kakao.client-secret, kakao.rest-api-key
  기본 client-id    : YOUR_KAKAO_REST_API_KEY (플레이스홀더)
  client-secret     : (비어 있음)
  로그인 URL        : http://localhost:8081/auth/kakao/login
  콜백 URL          : http://localhost:8081/auth/kakao/callback
  로컬 API mock     : kakao.local.mock-enabled=true (키 없을 때 UI 테스트)

  [네이버]
  설정 키           : naver.client-id, naver.client-secret
  기본 client-id    : YOUR_NAVER_CLIENT_ID (플레이스홀더)
  기본 secret       : YOUR_NAVER_CLIENT_SECRET (플레이스홀더)
  로그인 URL        : http://localhost:8081/auth/naver/login
  콜백 URL          : http://localhost:8081/auth/naver/callback

  실제 API 키 입력:
    - src/main/resources/application-local.properties.example 참고
    - application-local.properties 로 복사 후 키 입력 (git 제외 권장)
