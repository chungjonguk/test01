================================================================================
  React 개발환경 셋팅 가이드 (PrintMall)
  문서: docs/react-dev-setup.txt
================================================================================

[ 개요 ]
  Spring Boot(8081) 백엔드와 함께 React 프론트엔드를 개발하는 환경입니다.
  Vite + React + TypeScript 스택이며, frontend/ 폴더에서 UI를 작성합니다.

[ 필요 환경 ]
  - Node.js 22 LTS (npm 포함) — scripts\react-dev\install-node.ps1 로 자동 설치
  - JDK 17, Maven, MySQL (백엔드용 — 기존과 동일)
  - (선택) Cursor / VS Code + ESLint 확장

================================================================================
1. 빠른 시작 (최초 1회)
================================================================================

  1) React 개발환경 설치
     scripts\react-dev\setup-react-dev.bat

     → Node.js를 C:\Users\<사용자>\.local\dev\node-22 에 설치
     → frontend\ 에 npm 패키지 설치

  2) Spring Boot 백엔드 기동 (별도 터미널)
     run-server.bat

  3) React 개발 서버 기동
     run-react-dev.bat

  4) 브라우저
     http://localhost:5173/

================================================================================
2. 폴더 구조
================================================================================

  frontend/
    src/           React 컴포넌트·페이지
    public/        정적 파일
    vite.config.ts Vite 설정 (API 프록시 포함)
    package.json

  scripts/react-dev/
    install-node.ps1      Node.js portable 설치
    setup-react-dev.bat   전체 셋업 (Node + npm install)

  run-react-dev.bat       Vite dev 서버 실행

================================================================================
3. Spring Boot API 연동
================================================================================

  Vite dev 서버가 아래 경로를 localhost:8081 로 프록시합니다.

    /api/**   REST API
    /auth/**  로그인·OAuth

  React에서 fetch 예:
    fetch('/api/status')
    fetch('/api/admin/menus')

  백엔드가 꺼져 있으면 프록시 오류가 납니다 — run-server.bat 먼저 실행하세요.

================================================================================
4. npm 스크립트 (frontend 폴더)
================================================================================

  npm run dev      개발 서버 (5173)
  npm run build    프로덕션 빌드 → frontend/dist/
  npm run preview  빌드 결과 미리보기

================================================================================
5. Cursor / VS Code
================================================================================

  .vscode\tasks.json 작업:
    - React: 개발환경 셋업
    - React: Vite dev 서버

  실행: Ctrl+Shift+P → Tasks: Run Task

================================================================================
6. JDK/Maven 과 동일한 로컬 도구 경로
================================================================================

  JDK   : C:\Users\<사용자>\.local\dev\jdk-17
  Maven : C:\Users\<사용자>\.local\dev\apache-maven-3.9.15
  Node  : C:\Users\<사용자>\.local\dev\node-22

  run-react-dev.bat / setup-react-dev.bat 가 PATH에 Node를 자동 추가합니다.
  새 CMD/PowerShell 창에서 node/npm 을 쓰려면 사용자 PATH에 node-22 를 추가하세요.

================================================================================
7. 문제 해결
================================================================================

  ■ 'npm'은(는) cmdlet... 으로 인식되지 않습니다
    → setup-react-dev.bat 실행 또는 PATH에 node-22 추가

  ■ API 연결 실패 (5173에서 /api 호출)
    → run-server.bat 으로 8081 백엔드 기동 확인

  ■ npm install 느림 / 실패
    → 네트워크·프록시 확인 후 frontend 폴더에서 npm install 재실행

  ■ 포트 5173 사용 중
    → vite.config.ts 의 server.port 변경

================================================================================
