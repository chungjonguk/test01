반응형 웹 앱 (Responsive Web App)

PC · 태블릿 · 모바일 브라우저에서 동일 URL로 최적화된 Falcon UI

Bootstrap 5 Grid viewport meta d-none d-md-* @media CSS navbar vertical/top

1. 핵심 기술

항목구현
뷰포트layout.html — meta viewport width=device-width
그리드col-*, col-sm-*, col-md-*, col-lg-*, col-xxl-*
표시 제어d-none d-md-block — 모바일은 아이콘만, PC는 라벨
컨테이너container / container-fluid (isFluid localStorage)
커스텀 CSSuser.css, layout-navbar.css — @media (min-width: 576px/992px)
네비 전환navbar-position-settings.js — vertical ↔ top

2. 화면별 반응형 예

마법사: col-sm-10 col-lg-7 col-xxl-5, d-none d-md-block (탭 라벨)
대시보드: 카드 row + col — 브레이크포인트별 재배치
관리 화면: code-mgmt-table @media 가로 스크롤/열 숨김
마법사 전용: hideSidebar → container-fluid 전폭

3. 테스트 방법

Chrome F12 → 기기 툴바 (375px / 768px / 1400px) 또는 실제 스마트폰에서 http://localhost:8081 접속
