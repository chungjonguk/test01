1. 자주 쓰는 스크립트 (이 PC 기준)
--------------------------------------------------------------------------------

  [STS / Eclipse]
  open-sts-workspace.bat
    → STS 5.1.1 + 워크스페이스(E:\sts-workspace) 실행
    → sts-path.local.txt, sts-workspace.local.txt 경로 우선

  sync-eclipse-workspace.bat
    → scripts\eclipse\sync-eclipse-workspace.ps1 호출
    → Maven compile, .metadata, spring-boot-app 프로젝트 등록·junction 연동
    → STS 최초 연동 또는 프로젝트 구조 변경 후 1회

  fix-sts-before-run.bat
    → STS 실행 전 준비: 8081·8082 포트 점유 프로세스 종료
    → E:\nas-storage\printmall\uploads 하위 폴더 생성
    → mvn clean compile
    → STS에서 Maven Update Project(Alt+F5) 후 Run

  fix-eclipse-utf8.bat
    → 워크스페이스·프로젝트 UTF-8 prefs 적용 (한글 깨짐 방지)
    → STS 완전 종료 후 재실행 필요

  [DB 클라이언트]
  open-dbeaver.bat
    → DBeaver CE 실행
    → 연결 정보: scripts\dbeaver-postgresql-connection.txt

  [JAR 직접 실행]
  run-jar.bat
    → target\spring-boot-app-0.0.1-SNAPSHOT.jar 실행 (UTF-8)
    → 사전 빌드: mvn clean package -DskipTests

12. 주의사항
--------------------------------------------------------------------------------

  • run-server.bat, start-mysql.bat, create-all-tables.bat 등 MySQL 스크립트는
    PostgreSQL 전환 이후 사용하지 마세요.

  • setup-nas-storage.bat, backup-project-quick.ps1, pg-host-start.ps1 등
    D:\ 경로가 있는 스크립트는 이 PC에서 경로 수정 없이 실행하면 실패합니다.

  • fix-sts-before-run.bat 과 STS Run 을 동시에 여러 번 돌리면 포트 충돌이
  • 반복될 수 있습니다. 한 곳(Cursor / STS / 터미널)에서만 서버를 띄우세요.

  • application-local.properties 는 git 제외 — API 키는 setup-kakao-rest-key.ps1
    또는 수동 편집으로 관리하세요.
