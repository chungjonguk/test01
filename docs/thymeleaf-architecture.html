Thymeleaf 구성 (spring-boot-app-fixed)

Spring MVC + Thymeleaf 3 · Falcon 템플릿 · layout/fragment 패턴

1. 템플릿 디렉터리 구조

src/main/resources/templates/
├── layout.html              ← 공통 head/body fragment
├── fragments/
│   ├── sidebar.html         ← 사이드바 (th:href 메뉴)
│   ├── footer.html          ← footer fragment
│   └── app-loading.html
├── pages/                   ← 인증·FAQ·에러 등
│   └── authentication/wizard.html
├── dashboard/               ← 대시보드 화면
├── app/                     ← 앱(e-commerce, email…)
├── modules/                 ← Falcon 컴포넌트 데모
└── admin/                   ← 메뉴·공통코드 관리

2. 페이지 조립 패턴

각 화면 HTML:
  head  → th:replace="~{layout :: head}"
  body  → th:replace="~{layout :: body}"
           └── th:fragment="page-content"  ← 화면별 본문
  footer → th:replace="~{fragments/footer :: footer}"

3. application.properties (개발)

설정값의미
spring.thymeleaf.prefixfile:src/main/resources/templates/저장 즉시 반영
spring.thymeleaf.cachefalse개발 캐시 OFF
spring.thymeleaf.encodingUTF-8한글

4. 서버 → Model 주입

컴포넌트역할
PageViewAdviceURI별 loadEcharts, loadWizardKakaoAddress, kakaoMapAppKey …
PageCodeOptionsAdvice공통코드 콤보 __CODE_OPTIONS__
ScreenListServicetitle, screenId, screenNm
LoginSessionControllerAdvice로그인 세션 표시

5. layout.html 조건부 스크립트 (th:if)

th:if="${loadWizardKakaoAddress}"  → wizard-kakao-address.js
th:if="${loadLottie}"               → lottie.min.js
th:if="${loadTinymce}"              → tinymce (이메일 작성)
th:inline="javascript"              → __KAKAO_MAP_APP_KEY__, __CODE_OPTIONS__
