2. 개발 도구 설치 (install/dev-tools_*.zip)
================================================================================

  [2-1] 압축 해제

    1) D:\backup\install\dev-tools_YYYYMMDD_HHMMSS.zip 우클릭
    2) "압축 풀기" → 대상:
         C:\Users\<사용자명>\.local\dev\

    해제 후 폴더 예:
      C:\Users\<사용자명>\.local\dev\jdk-17\
      C:\Users\<사용자명>\.local\dev\apache-maven-3.9.15\
      C:\Users\<사용자명>\.local\dev\node-22\

  [2-2] PowerShell/CMD에서 확인

    set JAVA_HOME=C:\Users\<사용자명>\.local\dev\jdk-17
    set PATH=%JAVA_HOME%\bin;C:\Users\<사용자명>\.local\dev\apache-maven-3.9.15\bin;C:\Users\<사용자명>\.local\dev\node-22;%PATH%

    java -version     → 17.x
    mvn -version      → 3.9.x
    node -v           → v22.x
    npm -v            → 10.x

  [2-3] (선택) 사용자 PATH 영구 등록

    Windows 설정 → 시스템 → 정보 → 고급 시스템 설정 → 환경 변수
    Path에 추가:
      C:\Users\<사용자명>\.local\dev\jdk-17\bin
      C:\Users\<사용자명>\.local\dev\apache-maven-3.9.15\bin
      C:\Users\<사용자명>\.local\dev\node-22

  [2-4] zip 원본으로 재설치 (폴더 복원 실패 시)

    dev-tools zip 안의 설치 zip 사용:
      temurin17.zip      → jdk-17 폴더로 압축 해제 후 rename
      maven.zip          → apache-maven-3.9.15
      node-v22.15.1-*.zip → node-22

    또는 프로젝트 스크립트:
      spring-boot-app-fixed\scripts\react-dev\install-node.ps1

3. MySQL Server 8.4 설치
================================================================================

  백업 install 폴더에 MySQL 설치파일이 포함됩니다.

  [3-1] install 폴더 확인
    mysql-8.4.9-winx64.msi     MSI 설치 (권장)
    mysql-8.4.9-winx64.zip     ZIP portable
    mysql-setup_*.zip          DB·사용자 생성 SQL, my.ini, 배치

  [3-2] 설치 (MSI)
    mysql-8.4.9-winx64.msi 실행 → Port 3306, root 비밀번호 설정

  [3-3] DB·사용자 생성
    mysql-setup zip 압축 해제 후:
    mysql -u root -p < mysql-init-redcroxx.sql

  [3-4] 설치 경로 (기본)
    C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe

  [3-5] MSI/ZIP 없을 때
    powershell -File scripts\backup\download-mysql-installer.ps1
    또는 https://dev.mysql.com/downloads/mysql/8.4.html

  상세 → docs\03-mysql-설치방법.txt
