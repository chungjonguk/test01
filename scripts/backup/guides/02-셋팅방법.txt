2. MySQL DB 셋팅
================================================================================

  [2-1] 사용자·DB 생성 (최초 1회, root로 실행)

    mysql -u root -p < spring-boot-app-fixed\scripts\mysql-init-redcroxx.sql

    생성 결과:
      DB       : spring_boot_app
      사용자   : redcroxx
      비밀번호 : jonguk0412

  [2-2] DB 덤프 복원 (database/spring_boot_app_*.sql)

    mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS spring_boot_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
    mysql -u redcroxx -pjonguk0412 spring_boot_app < D:\backup\database\spring_boot_app_YYYYMMDD_HHMMSS.sql

    ※ 덤프가 없으면 앱 기동 시 스키마·시드가 자동 생성됩니다 (ScreenTableSchemaRunner).

  [2-3] DBeaver 연결

    Host     : 127.0.0.1
    Port     : 3306
    Database : spring_boot_app
    User     : redcroxx
    Password : jonguk0412

    JDBC URL:
    jdbc:mysql://127.0.0.1:3306/spring_boot_app?allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8

================================================================================

  ■ DB 접속 실패
    start-mysql.bat 또는 services.msc 에서 MySQL84 시작
    scripts\ensure-mysql.bat 실행
