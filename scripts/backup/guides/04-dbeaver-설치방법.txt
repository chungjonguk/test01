================================================================================
  DBeaver 설치방법 (DB 관리 도구)
  위치: D:\backup\docs\04-dbeaver-설치방법.txt
================================================================================

  PrintMall / 모의투자 MySQL(spring_boot_app) 접속용 GUI 도구입니다.

================================================================================
1. 백업 폴더의 DBeaver 관련 파일
================================================================================

  [install/]
    dbeaver-ce-25.3.1-x86_64-setup.exe     Windows 설치 (권장, ~110 MB)
    dbeaver-ce-25.3.1-win32.win32.x86_64.zip  ZIP portable (~123 MB)
    dbeaver-setup_YYYYMMDD.zip             연결 설정·가이드

  [dbeaver-setup zip 내용]
    data-sources.example.json   spring_boot_app 연결 프로필 예시
    dbeaver-mysql-connection.txt  수동 연결 절차
    README-dbeaver.txt            요약

================================================================================
2. 설치 — 방법 A (EXE, 권장)
================================================================================

  1) D:\backup\install\dbeaver-ce-25.3.1-x86_64-setup.exe 실행
  2) 설치 마법사 Next → Install → Finish
  3) 시작 메뉴 또는 바탕화면에서 DBeaver 실행

  ※ DBeaver는 내장 JRE를 포함하므로 별도 Java 설치 불필요합니다.

================================================================================
3. 설치 — 방법 B (ZIP portable)
================================================================================

  1) dbeaver-ce-*-win32.win32.x86_64.zip 압축 해제
     예) C:\Users\<사용자>\.local\dev\dbeaver\

  2) dbeaver.exe 실행

================================================================================
4. MySQL 연결 설정
================================================================================

  [방법 A] dbeaver-setup zip 의 data-sources.example.json 참고

  [방법 B] 수동 연결
    DBeaver → 데이터베이스 → 새 데이터베이스 연결 → MySQL

    Host     : 127.0.0.1
    Port     : 3306
    Database : spring_boot_app
    Username : redcroxx
    Password : jonguk0412

    Driver properties (MySQL 8.4):
      allowPublicKeyRetrieval = true
      useSSL = false

    JDBC URL:
    jdbc:mysql://127.0.0.1:3306/spring_boot_app?allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8

  [방법 C] 프로젝트 연결 가이드
    spring-boot-app-fixed\scripts\dbeaver-mysql-connection.txt

  ※ MySQL이 먼저 기동되어 있어야 합니다 (run-server.bat 또는 services.msc).

================================================================================
5. 연결 프로필 가져오기 (선택)
================================================================================

  DBeaver → 파일 → 가져오기 → DBeaver → 프로젝트
  또는 data-sources.example.json 내용을 참고해 동일하게 입력

  프로젝트 .dbeaver/data-sources.json (Cursor용)과 별개입니다.
  DBeaver CE는 자체 workspace에 연결 정보를 저장합니다.

================================================================================
